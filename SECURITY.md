# Seguridad

## Alcance

Este repositorio es una demostracion local. No almacena ni solicita contrasenas
de portales externos y no incluye adaptadores para servicios reales de citas.

## Configuracion

- Mantener `.env` fuera de Git.
- Usar valores aleatorios diferentes para `API_TOKEN`, `DB_PASSWORD`,
  `MYSQL_ROOT_PASSWORD` y `DEMO_ACCESS_CODE`.
- No exponer MySQL ni el portal de demostracion a Internet.
- No adjuntar bases de datos, cookies, perfiles del navegador, capturas o logs
  con informacion personal.

## Reporte responsable

Si encuentras una vulnerabilidad, no publiques datos de prueba ni una prueba de
concepto operativa. Abre un reporte privado al responsable del repositorio.
